## About

The Sarcastic Swede's Movie Journal is a personal movie-tracking application built for people who love movies and want more than a simple watchlist.

Instead of merely recording whether you have seen a film, the journal lets you create a lasting record of your movie experiences through personal ratings, notes, viewing statistics, and recommendations.

Whether you are a casual movie watcher or a lifelong film enthusiast, this project helps tell the story of your life through cinema.

## Current Features — v1.4 Beta

### 🔍 Movie Search

Search thousands of films using The Movie Database (TMDB), with movie posters, plot summaries, release dates, ratings, and detailed information.

### ✅ Watch Tracking

- Mark movies as watched
- Automatically record the watch date
- Remove movies from your journal
- Save everything in browser Local Storage

### ⭐ Personal Ratings

- Five-star personal rating system
- Ratings kept separate from TMDB scores
- Highlight your own favorites

### 📝 Personal Movie Journal

Add personal notes, reviews, favorite moments, memories, and thoughts to every watched movie.

### 📊 Dashboard

Explore your viewing habits through charts and statistics, including:

- Total movies watched
- Average personal rating
- Most-watched release decades
- Monthly viewing activity
- Genre statistics
- Personal rating distribution

### 🍿 Recommendations

Receive movie recommendations based on your highest-rated films. Rating more movies helps improve the results.

### 📄 CSV Export

Export your movie journal to a CSV file for backup or further analysis.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
- TMDB API

The current version is a standalone application with no build process or package installation required.

## Getting Started

### Use the application

1. Download or clone this repository.
2. Open the movie journal HTML file in a modern browser.
3. Search for a movie.
4. Mark it as watched.
5. Add a personal rating and notes.
6. Explore your dashboard and recommendations.

### Clone with Git

```bash
git clone https://github.com/Ridge3d/the-sarcastic-swedes-movie-journal.git
```

## Privacy and Data Storage

Your journal data is stored locally in your browser using Local Storage.

- No account is required
- Journal entries are not uploaded to a project server
- Each browser and device maintains its own separate collection
- Clearing browser data may remove saved journal entries

Use the CSV export feature to keep an external backup of your movie history.

## Why This Project Exists

There are plenty of movie-tracking websites, but most focus primarily on creating lists.

This project focuses on creating memories.

Movies are not simply titles you have watched—they are experiences. The goal of this journal is to preserve those experiences and build a personal cinematic history worth revisiting.
